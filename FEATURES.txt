Current backend behaviour
  - Squad voice (PartyWin + LocalBackend party.voice; Opus/RNNoise)
  - Mission XP Share: joiners get XP / medals / requisition via mission.ended
  - Samples: extract pool for everyone who extracted (sum of extracted lootedItems)
  - Weapon XP: progressedPackages → packageProgress on disk
  - Mission/end: badges[] always empty (filled lists break parser 0x105e3e0)
  - Mission/end: full progressionPackageUpdates snapshot (not a single package)
  - Unattributed co-op Mission/end does not burn paidMissions with a zero payout
  - Sample share: fall back to the host pool; log sample units
  - Superstore: /StoreFront/rotation and /StoreFront/{id}; buys spend Forge Credits
  - Pickup share: medal / requisition / Forge Credit piles in the lobby

Installer (v20)
  - Installs real + thin wrapper + steam_api64.spacewar.dll (Spacewar 480)
  - On stock 0.2.0 (one large LocalBackend.exe) creates the real/wrapper split
  - On portable 0.4 only refreshes the patched files
  - skip-steam-check + HellForge-Portable.cmd
  - Does not touch profiles\

Limits
  - GET /Progression once per session; joiner armory UI may lag until relaunch
  - extracted:false → 0 samples even on success
  - PartyWin pin in build.json must match original game\bin\PartyWin.dll for that HellForge build
  - Everyone in the squad must run the same LocalCoop_vN
